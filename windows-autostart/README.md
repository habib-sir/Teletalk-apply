# সার্ভার স্বয়ংক্রিয়ভাবে চালু রাখা (Windows)

এটা সেটআপ করলে, PC অন হলেই সার্ভার নিজে থেকে ব্যাকগ্রাউন্ডে চালু হয়ে যাবে —
কোনো কালো cmd উইন্ডো দেখাবে না, আর আপনাকে কখনো ম্যানুয়ালি `node server.js`
টাইপ করতে হবে না। Extension-এর বাটন তখন সবসময় কাজ করবে কারণ সার্ভার সবসময়
প্রস্তুত থাকবে।

## ধাপ ১: ফোল্ডার বসান

`windows-autostart` ফোল্ডারটা আপনার `Autofill-Job-apply` প্রজেক্ট ফোল্ডারের
ভেতরে বসান (যেখানে `server.js` এবং `package.json` আছে, ঠিক তার পাশে)।

```
Autofill-Job-apply/
  server.js
  package.json
  windows-autostart/
    start-server.bat
    start-server-hidden.vbs
```

## ধাপ ২: একবার ম্যানুয়ালি টেস্ট করুন

`start-server.bat` ফাইলে ডাবল-ক্লিক করুন। একটা কালো উইন্ডো খুলে
`BD Job Autofill Server running on http://0.0.0.0:3000` লেখা দেখাবে —
মানে কাজ করছে। উইন্ডোটা বন্ধ করলে সার্ভারও বন্ধ হয়ে যাবে (এটা স্বাভাবিক,
এটা শুধু টেস্ট)।

## ধাপ ৩: শর্টকাট বানান

1. `start-server-hidden.vbs` ফাইলে **right-click** করুন
2. **Create shortcut** সিলেক্ট করুন — একই ফোল্ডারে একটা শর্টকাট তৈরি হবে
   (`start-server-hidden.vbs - Shortcut` নামে)

## ধাপ ৪: Startup ফোল্ডারে বসান

1. কীবোর্ডে **Win + R** চাপুন
2. টাইপ করুন: `shell:startup` তারপর Enter — এটা Windows-এর Startup ফোল্ডার খুলবে
3. ধাপ ৩-এ তৈরি করা শর্টকাটটা **কেটে (Cut) এই ফোল্ডারে পেস্ট** করুন
   (মূল `.vbs` ফাইলটা প্রজেক্ট ফোল্ডারেই থাকবে, শুধু শর্টকাটটা Startup-এ যাবে)

## ব্যাস, শেষ!

এখন থেকে PC restart/login দিলেই সার্ভার নিজে থেকে ব্যাকগ্রাউন্ডে চালু হয়ে
যাবে। চেক করতে চাইলে:

- **Task Manager** খুলুন (Ctrl+Shift+Esc) → **Details** ট্যাব → `node.exe`
  নামে একটা প্রসেস চলছে কিনা দেখুন
- অথবা ব্রাউজারে গিয়ে `http://localhost:3000` খুললে JSON/পেজ লোড হচ্ছে কিনা দেখুন

## বন্ধ করতে চাইলে

Task Manager থেকে `node.exe` প্রসেসটা End Task করুন, অথবা Startup ফোল্ডার
থেকে শর্টকাটটা মুছে দিন (পরের বার লগইনে আর চালু হবে না)।

## একটা ছোট সতর্কতা

এই সার্ভার আপনার PC-র ৩০০০ পোর্টে চলবে এবং লোকাল Wi-Fi নেটওয়ার্কের যে কেউ
(যদি কেউ আপনার Wi-Fi-তে থাকে) তাত্ত্বিকভাবে এতে রিকোয়েস্ট পাঠাতে পারবে,
কারণ `server.js`-এ CORS `*` (সবার জন্য খোলা) করা আছে। বাসার Wi-Fi-তে এটা
সাধারণত ঝুঁকিমুক্ত, কিন্তু পাবলিক/অফিসের Wi-Fi-তে এই সার্ভার চালু রাখা
এড়িয়ে চলাই ভালো।
